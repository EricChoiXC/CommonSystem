### 1.2 当前版本范围

- 版本目标：为公共模块工程新增多语言管理能力，模块包 `com.common.system.sys.i18n`，前端补 vue-i18n 基建与三个维护页面。
- **In Scope**
  - 四张表（`sys_i18n_language` / `sys_i18n_key` / `sys_i18n_translation` / `sys_i18n_user_language`），迁移脚本 `V1_01_040`。
  - 启动同步（初始语言保证 + `resources/i18n/**` 扫描 + 覆盖规则）与部署动作（手动触发同规则同步 + 刷新缓存）。
  - 14 个接口：language 5 个、model 1 个、translation 5 个、deploy 1 个、`/locales/{code}.json` 1 个、user/language 1 个；权限码 `SYS_I18N_ADMIN`。
  - 后端缓存（内存 Map + Redis Hash + 本地兜底）与 `I18nService.message(...)`。
  - 登录语言登记契约（`SysOrgLoginRequest.fieldLanguage` + upsert）。
  - 前端：vue-i18n 基建、语言管理 / 翻译维护 / 部署三个页面、登录页语言下拉、顶部栏语言切换、菜单与路由登记。
- **Out of Scope**
  - `sys_i18n_key` 人工新增 / 删除入口（D5 已确认：key 仅随资源文件扫描产生）。
  - 存量模块（org / process / task 等）页面与服务文案的 i18n 化改造（本版本只建机制 + `org` 示例资源集，存量迁移为后续迭代）。
  - 语言包构建产物落盘（D2 已确认：走 `/locales/{code}.json` 动态接口）。
  - ERP 侧改动（本仓库不含 ERP 模块）。

### 1.3 任务拆解规则

- 按功能切片组织：`I18N0` 基线与文档、`I18N1` 数据与契约、`I18N2` 启动同步与缓存、`I18N3` 语言管理、`I18N4` 翻译维护、`I18N5` 部署与语言包、`I18N6` 用户语言与前端国际化基建、`I18N7` 联调验收。
