- 版本目标：为公共模块工程建立导入导出公共通道（注解声明 + 工具类 + 公共业务层 + `BaseCrudController` 公共方法 + 前端公共弹窗与下载工具），并完成 i18n 模块对齐与 dict 试点接入。
- **In Scope**
  - 后端基础层：`@Export` 注解、`ImportExportUtils`（固定 VO 通道 3 方法 + 自定义字段 Map 通道 2 方法 + `buildModelMap` 反射辅助）、`ImportResultVo`、`ImportRowHandler`、`ImportExportService`、`BaseCrudController` 追加 3 个 protected 方法与可选 4 参构造。
  - 前端公共层：`api/index.js` 拦截器 blob 透传修复（公共方案必要前置）、`utils/download.js`、`api/common.js` 追加 3 函数、`components/ImportDialog.vue` + 注册。
  - i18n 模块对齐（Q6）：导入结果迁移公共结构（继承扩展）、导出文件名带时间戳、前端切换公共弹窗与下载工具。
  - dict 试点接入（Q7）：`ACTION_*` 常量、resolver 分支、三接口（export/import/template）、导出/导入 VO、前端页面接入。
  - 文档同步（方案设计 10.3）：标准.md 三处修正回写、开发规范与 `AGENTS.md` 接口表补 `/template`、系统模块 API 文档登记、前端公共组件契约登记。
- **Out of Scope**
  - 不新增数据库表与迁移脚本（导入导出无持久化模型变更，方案设计 1.3）。
  - 不新增 `roles.yml` 权限角色码（复用各模块既有管理角色，方案设计 10.2）；「可导出不可导入」细分权限码留作后续演进。

  - `ImportExportService` 不为 Map 通道增加重载（方案设计 6.1.2：出现第二个 Map 通道接入方时再评估，届时补设计）。
  - Map 通道 `dict` / `dateFormat` 扩展键首版不实现（Q8，预留）。
  - 导入大文件分批事务 + 断点续传（方案设计 6.4：数万级行数单事务可接受，数据量增长再演进）。
  - ERP 侧模块接入（本仓库不含 ERP 模块，方案可被 ERP 侧直接引用）。

- 按功能切片组织：`IE0` 基线与口径回写、`IE1` 后端公共契约层、`IE2` 前端公共层、`IE3` i18n 对齐改造、`IE4` dict 试点接入、`IE5` 联调验收与文档同步。

- **强顺序约束**：
  - `IE2-FE-001` 拦截器 blob 修复必须先于所有依赖文件流通道的前端任务（`IE2-FE-002`、`IE3-FE-001`、`IE4-FE-001`）——方案设计 8.2 明确其为「公共方案的必要前置」，否则导出下载在当前实现下不可用；
