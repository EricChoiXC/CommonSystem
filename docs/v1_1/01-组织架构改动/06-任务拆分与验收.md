### 1.2 当前版本范围

- 版本目标：把角色纳入组织架构子类（`field_org_type = 5`），并新增群组类型（`field_org_type = 6`）及其维护页面与地址本选择能力。
- **In Scope**
  - 角色：主表镜像行 + 同事务双写、常量与码值、树/列表排除、地址本「角色」页签。
  - 群组：三张表、可见性与维护权限、5 个维护接口 + 2 个地址本接口、列表/编辑/详情页面、顶栏图标 + 菜单项、地址本「群组」页签。
- **Out of Scope**
  - 存量角色数据迁移（明确不做；仅提供离线可选脚本）。
  - 角色删除接口（当前无，本次不新增）。
  - 群组的组织架构树挂载、群组层级、群组嵌套。
  - 业务模块（待办/流程/日程）对群组的直接引用（本次仅提供地址本「批量选人」能力）。
  - ERP 侧改动（本仓库不含 ERP 模块）。

- **影响范围**

| 类型 | 路径 |
| --- | --- |
| 迁移脚本 | `backend/src/main/resources/db/migration/V1_01_039__*.sql` |
| 配置 | `backend/src/main/resources/properties/sys/org/{dict,roles}.yml` |
| 后端 | `com.common.system.sys.org.{properties,model,dao,mapper,request,response,service,resolver,controller}`、`resources/mappers/sys/org/` |
| 前端 | `frontend/src/{router,api,components,views}` |
| 文档 | `docs/设计文档/sys/org/*`（5 份）、`docs/系统模块/*`（4 份） |

### 1.3 任务拆解规则

- 按业务模块垂直切片：`ORG1`（角色）、`ORG2`（群组）各自闭环；`ORG0` 为两者共用的基线任务。
- 顺序：文档 → 数据库/配置 → 后端契约与实现 → 前端 → 联调 → 验收 → 文档同步。
- **先做排除类改动（ORG1-BE-003）**：角色镜像行一旦写入，未排除的树查询会立刻出现脏节点，故该任务必须先于镜像行双写（ORG1-BE-002）上线。
- 文档同步不默认「顺手更新」，均列为显式任务（`*-DOC-*`）。
- 未决事项不进入编码任务，标 `BLOCKED` 并写清解锁条件。
