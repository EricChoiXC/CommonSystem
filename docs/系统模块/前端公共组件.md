# 一. 地址本

1. 提供组织架构的选择

2. 要求实现弹窗，弹窗界面分上中下三层；

3. 上层为唯一文本输入框输入关键字，和查询按钮；

4. 下层为已选项显示和确认、取消按钮；

5. 中层分两个页签，将受“可选组织架构类型”影响而显示；

6. 中层第一页签：组织架构树：划分左右两个区域，左侧为从根节点点击展开的组织架构层级关系，此处的点击不会选中数据，而是将查询以该数据作为上级节点的组织架构数据列出在右侧区域；由右侧区域进行数据选中。

7. 中层第二页签：查询页签：此处为常用的列表分页查询，只根据上层的关键字输入框进行查询

8. 组件绑定参数如下：

   | 参数名     | 说明                                                         |
   | ---------- | ------------------------------------------------------------ |
   | fieldId    | 关联的id值字段，必填                                         |
   | fieldName  | 关联的名称值字段，必填                                       |
   | orgType    | 可选的组织架构类型，默认'ALL'<br />ALL - 全部<br />ORG - 机构<br />DEPT - 部门<br />ORGDEPT - 机构或部门<br />PERSON - 人员<br />POST - 岗位 |
   | multi      | 是否多选，默认 `false`                                       |
   | septarator | 多选的分隔符，默认';'，要求仅限符号                          |
   | limitRange | 限制的组织架构范围，默认为空，填入组织架构的 `fieldId` 值数组，限制范围体现在组织架构树的根节点，和列表查询默认条件上 |
   | callback   | 确认选择后的回调函数                                         |

# 二. 附件组件

1. 提供附件的上传、下载等功能

2. 组件绑定参数如下：

   | 参数名         | 说明                                                         |
   | -------------- | ------------------------------------------------------------ |
   | fieldModelId   | 传递给接口的`fieldModelId`字段值                             |
   | fieldModelName | 传递给接口的`fieldModelName`字段值，必填                     |
   | fieldKey       | 传递给接口的`fieldKey`字段值                                 |
   | multi          | 是否可上传多个附件，默认`false`                              |
   | fileType       | 可上传的文件后缀类型，默认为空（不限制）                     |
   | uploadCallback | 上传结束后的回调函数                                         |
   | uploadValidate | 确认上传文件到触发后端上传接口中间的校验函数，函数不为空时要求函数返回必须是 `true` 才能继续上传 |
   | deleteCallback | 删除结束后的回调函数                                         |

# 三. 选择器组件

1. 提供对数据库来源数据的选择

2. 组件绑定参数如下：

   | 参数名     | 说明                                                         |
   | ---------- | ------------------------------------------------------------ |
   | fieldId    | 关联的id值字段，必填                                         |
   | fieldName  | 关联的名称值字段，必填                                       |
   | url        | 请求的列表查询接口url，必填                                  |
   | filter     | 可筛选项，对象数组，对象示例如下：<br />`{"text" : "查询的中文名", "name" : "查询的字段名称"}`<br />默认值： `[{"text" : "名称", "name" : "fieldName"}]` |
   | show       | 列表显示项，对象数组，对象示例如下：<br />`{"text" : "显示的中文名", "name" : "显示的字段名称"}`<br />默认值： `[{"text" : "名称", "name" : "fieldName"}]` |
   | multi      | 是否多选，默认 `false`                                       |
   | septarator | 多选的分隔符，默认';'，要求仅限符号                          |
   | callback   | 确认选择后的回调函数                                         |

# 四. 树形选择器组件

1. 提供对树形数据表数据的选择，在「三. 选择器组件」基础上改造：节点懒加载查询，请求体携带 `fieldParentId`（上级 id，根级为空）查询直接下级；无筛选区。

2. 组件绑定参数如下：

   | 参数名        | 说明                                                         |
   | ------------- | ------------------------------------------------------------ |
   | fieldId       | 关联的id值字段，必填                                         |
   | fieldName     | 关联的名称值字段，必填                                       |
   | url           | 树节点懒加载查询接口url，必填（POST，请求体 `{ fieldParentId, ...params }`） |
   | fieldParentId | 上级id字段入参：弹窗打开时树从该上级节点的直接下级开始加载，为空则从根级（fieldParentId 为空）加载 |
   | labelField    | 节点名称显示字段，默认 `fieldName`                           |
   | multi         | 是否多选，默认 `false`                                       |
   | septarator    | 多选的分隔符，默认';'，要求仅限符号                          |
   | checkStrictly | 多选时父子节点勾选是否联动，默认 `true`（严格模式：勾选父节点不影响子节点） |
   | params        | 请求树节点时额外携带的固定参数（如 orgTypes 等），默认 `{}`   |
   | callback      | 确认选择后的回调函数                                         |

# 五. 分类表格选择器组件

1. 提供「按树形分类筛选主表、勾选主表记录回填」的选择能力：弹窗左侧为树形分类（懒加载，选中项作为主表指定字段的等值查询条件，「全部」清除分类条件），右侧为主表分页列表（支持名称模糊过滤），勾选主表记录后确认回填；与「四. 树形选择器组件」的区别：树形选择器直接选择分类节点回填，本组件回填的是分类条件下筛选出的主表记录。

2. 组件绑定参数如下：

   | 参数名        | 说明                                                         |
   | ------------- | ------------------------------------------------------------ |
   | fieldId       | 关联的id值字段，必填                                         |
   | fieldName     | 关联的名称值字段，必填                                       |
   | treeUrl       | 分类树懒加载接口url，必填（POST，请求体 `{ fieldParentId, ...treeParams }`，按 fieldParentId 返回直接下级） |
   | tableUrl      | 主表列表接口url，必填（POST，请求体 `{ body: { [categoryField], fieldName, ...tableParams }, pages: { pageNo, pageSize, needPage }, sortField, sortOrder }`，分页总数经 `metadata.total` 返回） |
   | categoryField | 主表分类条件字段名，必填（等值匹配，如客户 `fieldCateId` / 项目 `fieldCategoryId`） |
   | columns       | 右侧列表显示列配置，必填，数组项 `{ prop, label, width?, minWidth?, formatter? }` |
   | labelField    | 树节点名称显示字段，默认 `fieldName`                         |
   | multi         | 是否多选，默认 `false`（单选；仅「其他xxx」等多值字段显式传 `multi`，多选跨页累积勾选，`false` 时点击行单选） |
   | septarator    | 多选的分隔符，默认';'，要求仅限符号                          |
   | treeParams    | 请求树节点时额外携带的固定参数，默认 `{}`                    |
   | tableParams   | 请求主表列表时额外携带的固定参数（合并进 body），默认 `{}`   |
   | callback      | 确认选择后的回调函数                                         |

3. 当前适用场景（两场景分类树接口均返回 `field_id` / `field_name` / `field_parent_id` / `is_leaf` 等公共字段）：

   | 场景             | treeUrl                                      | tableUrl                               | categoryField       | 右侧列表列                                     |
   | ---------------- | -------------------------------------------- | -------------------------------------- | ------------------- | ---------------------------------------------- |
   | 业务单位 + 单位分类 | `/backend/erp/mdm/unitCategory/list`      | `/backend/erp/mdm/unit/list`           | `fieldCateId`       | 业务单位名称、单位类型、状态、统一社会信用代码 |
   | 项目 + 项目分类  | `/backend/erp/project/category/list`         | `/backend/erp/project/main/list`       | `fieldCategoryId`   | 项目名称、项目编号、项目状态、负责人           |

4. 说明：
   - 左侧选中分类后右侧按 `categoryField` 等值查询；未选分类（或点「全部」）时返回主表全量。客户页与组件默认行为一致，仅匹配当前分类；项目列表页（`/project`）与合同列表页（`/contract`）例外：选中父分类时会包含其全部后代子分类下的项目 / 合同（后端按分类范围（含后代）IN 查询）。
   - 已选项回显仅限当前页已加载的记录；跨页已选项无法自动定位，翻页后勾选即可跨页累积。

# 六. 日期时间选择器

提供对日期、时间等数据要求的选择，包含多个不同类型的选择器

## 4.1 日期时间选择器

1. 可从日期、时间、日期时间进行选择，包含对特定场景进行选择

2. 绑定参数如下

   | 参数名         | 说明                                                         |
   | -------------- | ------------------------------------------------------------ |
   | fieldName      | 选择器关联的字段，可选（用于 name 属性与单值类型占位提示）                                       |
   | calendarType   | 选择器类型，默认 `datetime`<br />year - 年<br />month - 年月<br />week - 周<br />date - 日期<br />daterange - 日期范围<br />time - 时间<br />datetime - 日期时间<br />datetimerange - 日期时间范围 |
   | dateFormat     | 日期格式，默认 `YYYY-MM-DD`，可按 `calendarType` 约束为 `YYYY`、`YYYY-MM`、`YYYY-MM-DD` 等 |
   | timeFormat     | 时间格式，默认 `HH:mm:ss`，可按 `calendarType` 约束为 `HH`、`HH:mm`、`HH:mm:ss` 等 |
   | datetimeFormat | 日期时间格式，默认 `YYYY-MM-DD HH:mm:ss`，可按业务需要配置为只到时或时分 |
   | yearRange      | 可选年份范围或年份列表，如 `2024-2030`、`[2024,2025,2026]`                                  |
   | monthRange     | 可选月份范围或月份列表，如 `1-12`、`[1,3,5,7,9,11]`                                          |
   | hourRange      | 可选小时范围或小时列表，如 `6-18`、`[8,9,10,14,15,16]`                                       |
   | minuteRange    | 可选分钟范围或分钟列表，如 `0-59`、`[0,15,30,45]`                                            |
   | weekDays       | 可选星期范围或星期列表，如 `[1]`、`[1,2,3,4,5]`，约定 `1` 为星期一，`7` 为星期日                |
   | placeholder    | 单值类型占位提示覆盖，不传时按 `fieldName` 生成「请选择 + fieldName」                |
   | startPlaceholder | 范围类型起始占位提示，默认 `开始时间`                                             |
   | endPlaceholder | 范围类型结束占位提示，默认 `结束时间`                                               |
   | rangeSeparator | 范围类型分隔符，默认 `至`                                                         |

3. 范围类型（`daterange` / `datetimerange`）绑定值为数组 `[开始, 结束]`；单值与范围类型变更时均抛出 `change` 事件。

4. 格式统一使用 dayjs token（如 `YYYY-MM-DD`、`YYYY-MM-DD HH:mm:ss`）；`format` 与 `value-format` 均取对应格式参数。
