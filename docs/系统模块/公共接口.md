# 公共接口

> 公共接口文件类统一开发在 `common` 包下

## 一：initID

无入参，无权限要求；

按照要求生成一个ID字符串并返回；

> ID长度为32位；由 毫秒级时间戳转字符串， + UUID v4 生成随机字符串 补位至32位

## 二：init

无入参，无权限要求；

返回系统初始化基础信息，供前端公共展示位（顶部菜单栏 LOGO 等）读取；

返回结构：`{ "applicationName": "星辰ERP" }`

> `applicationName` 取 `application.properties` 的 `application.name` 配置项；
> 配置项缺失或为空时回退为 `ERP`。
