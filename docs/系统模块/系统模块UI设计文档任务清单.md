### 1.2 使用说明

- 本清单用于驱动 [系统模块UI设计文档](D:/Program/erp/docs/系统模块/系统模块UI设计文档.md) `4. 模块级页面设计` 的逐页补齐。
- 执行任务时，直接回写既有 UI 详设文档，不新建重复页面正文文档。
- 当前需求文档未给出稳定的功能 ID / 规则 ID / 验收 ID；本清单采用“需求章节锚点编号”作为临时来源标识，供后续 UI/API/DB 文档统一引用。
- 每个任务完成后，必须同步更新本清单状态、回写对应页面章节，并补充新增待确认事项。

### 1.3 来源编号规则

- 需求章节编号采用 `REQ-<模块>-<序号>`，例如 `REQ-ORG-001`。
- 规则编号采用 `RULE-<模块>-<序号>`，例如 `RULE-PROCESS-002`。
- 验收编号采用 `AC-<模块>-<序号>`，例如 `AC-NOTIFY-001`。
- 页面编号采用 `PAGE-SYS-<三位序号>`，任务编号采用 `UI-SYS-<三位序号>`。

## 4. 当前波次建议

### Wave 1

- 优先目标：先补齐系统基础主数据与个人主路径页面，形成组织、权限、字典、待办三个高频入口的评审闭环。
- 包含任务：`UI-SYS-001`、`UI-SYS-002`、`UI-SYS-003`、`UI-SYS-004`、`UI-SYS-006`、`UI-SYS-017`、`UI-SYS-023`
- 进入条件：现有 [系统模块UI设计文档](D:/Program/erp/docs/系统模块/系统模块UI设计文档.md) 模块级骨架已确认可继续细化。
- 退出条件：组织架构主链路、我的待办主链路、码值维护主链路具备逐页可评审正文。

### Wave 2

- 优先目标：补齐组织架构剩余关联界面、附件能力和编号规则能力，完善公共支撑页面。
- 包含任务：`UI-SYS-005`、`UI-SYS-007`、`UI-SYS-008`、`UI-SYS-009`、`UI-SYS-014`、`UI-SYS-015`、`UI-SYS-016`
- 进入条件：Wave 1 中的页面命名、控件命名、页面章节命名已稳定。
- 退出条件：公共支撑模块具备完整 UI 承接面，后续 API/DB 可按页面字段与操作继续落细。

### Wave 3

- 优先目标：补齐流程机制与待办联动页面，形成审批链与监管链的页面基线。
- 包含任务：`UI-SYS-010`、`UI-SYS-011`、`UI-SYS-012`、`UI-SYS-013`、`UI-SYS-018`、`UI-SYS-019`、`UI-SYS-020`、`UI-SYS-021`
- 进入条件：组织架构、待办基础命名和权限表达方式已稳定，可复用到流程页面。
- 退出条件：流程模板、流程实例、待办个人页、监管页完成可评审补文。

### Wave 4

- 优先目标：补齐审计页面并收敛跨模块待确认事项。
- 包含任务：`UI-SYS-022`
- 进入条件：前序模块的页面命名、权限术语与状态表达已收敛。
- 退出条件：系统模块 UI 详设逐页任务全部具备执行入口，待确认事项有清晰归口。
