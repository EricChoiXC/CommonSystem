### 1.2 当前版本范围

- 版本目标：交付自定义表单模块 `com.eric.base.sys.form`——统一组件协议与前端物料库、表单设计器（拖拽/属性配置/规则配置/预览/发布/Schema 导入导出）、动态表单渲染器（配置/编辑/详情三形态复用）、动态规则引擎（显隐/联动/动态校验/公式计算）、明细表组件、表单数据引擎（JSON 存储、保存/回显/校验/查询、服务端动态校验与字段权限裁剪）、表单版本管理（不可变版本、回滚=重发布副本）、表单管理页面与路由菜单；为 v1.8 BPM 预留权限组件协议位与字段级权限元数据。
- In Scope：
  - 组件协议：统一组件元数据结构（type/label/category/icon/defaultProps/数据类型/校验器/默认值生成器/序列化），组件全集以组件文档为基线经 R03 裁决定稿；
  - 表单设计器：三区域（物料栏/画布/属性与规则面板）、拖拽排序、复制删除、撤销重做、预览、Schema 导入导出、发布入口；
  - 动态渲染器：schema → 组件树、数据绑定/初始化/回显/重置、字段级权限渲染（只读/隐藏）、配置/编辑/详情三形态；
  - 规则引擎（前后端各一）：显隐、联动、动态校验、公式计算字段（集成 F14 `FormulaEngine`），事件总线 + 循环防护；
  - 明细表：增删行、行内编辑、行内规则、自动计算（行内公式 + 合计）；
  - 表单定义管理：草稿 CRUD、Schema 结构校验、发布产生不可变版本、版本列表、回滚=重发布历史版本副本；
  - 表单数据引擎：JSON 存储、保存/回显/删除/查询、schema 驱动基础校验、动态校验、隐藏字段数据裁剪、数据归属控制；
  - 数据库：`sys_form` / `sys_form_version` / `sys_form_data` 起步（表清单随 R05 裁决），实体注解建表；
  - 前端：`api/form.js`、`components/form/`（物料库 + 渲染器 + 设计器）、管理页/填写页/数据详情页、路由与菜单、`views/ui.vue` 样例登记。
- Out of Scope（裁决倾向，随 Wave 0 裁决定稿）：
  - BPM 深度集成（流程绑定表单、节点字段权限运行时、节点显隐/必填、审批意见组件、流程结束归档）→ v1.8 BPM；本模块仅预留权限组件协议位与字段级权限元数据（组件文档权限组件自注「1.8 BPM 上需使用」，开发计划依赖图为 `自定义表单 → BPM`）；
  - JS 响应函数执行引擎（代码块组件运行时）→ 随 R02 裁决，倾向一期仅预留协议、二期以隔离环境（GraalJS/受限解释器）落地（要点文档安全建议：不使用 `eval`，后端不信任前端 JS 返回结果）；
  - 自定义 Vue 组件接入（`sys_form_component` 注册）→ 二期；
  - 表单模板库、表单数据导入导出 → 二期；
  - 多级嵌套明细表（子表嵌套子表）→ 随 R04 裁决，倾向一期一层明细表；
  - 自动编号组件 → 随 R05 裁决，倾向二期复用 NumberRuleComposer/取号接口；
  - 结构化业务数据映射层与报表统计 → 不排期（要点文档第 6 步：后续按需增加映射层，不一开始为动态表单建独立业务表）。
- 影响范围：`backend/src/main/java/com/eric/base/sys/form/`、`backend/src/main/resources/mappers/sys/form/`、`backend/src/main/resources/properties/sys/form/`、`backend/pom.xml`（如引入沙箱依赖，随 R02）、`backend/src/test/java/`、`frontend/src/{api,components,views,router,views/HomeView.vue}`、`frontend/package.json`（拖拽/编辑器依赖，随 R07）、`docs/`、`AGENTS.md`。

### 1.3 任务拆解规则

- 按「F15 自定义表单」单模块垂直切片，先文档裁决后契约、先协议后引擎、先数据后接口、先渲染器后设计器、先联调后收尾。
- 组件协议、Schema 协议、规则协议、渲染器契约四件套先定稿（要点文档第七节最终建议：先定四个基础再写组件），再铺开组件物料与页面实现。
- 后端按「协议模型与常量 → 定义/版本 Service → 数据引擎 → 动态校验与权限裁剪 → 公式集成 → Controller」推进，引擎类落 `service/engine` 次级包（先例 formula `service/engine`）。
- 表结构一律实体注解（`@TableSource` / `@ColumnField` / `@TableIndex`）+ 注解同步引擎，禁止新增迁移脚本；本模块为全新表、无存量回填，无需 `SourceDataMigration`。
- 要点文档第 9 步的 REST 风格接口（`POST /forms`、`PUT /forms/{id}`）与后端包结构（domain/repository）为通用建议，落地一律映射为仓库接口矩阵与分层规范，映射关系在功能设计中显式登记。
- 文档同步不靠「顺手更新」：Wave 0 显式产出四份设计分册，收尾设回查任务；Controller Swagger 注解与代码同批完成。
- 验证基线：`cd backend && ./mvnw test`（含 `ApiDocsTest`）、`cd frontend && npm run build`；集成验证期启动的服务结束前停止。
