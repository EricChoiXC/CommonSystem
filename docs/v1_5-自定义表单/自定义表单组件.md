# 1. 自定义表单组件

1. 本组件是一个在前端开发使用的组件，功能包含表单配置、封装xml、解析xml生成配置页，编辑页，详情页；

> 裁决标注（F15-DOC-001，2026-11-23）：「封装 xml、解析 xml」表述经 R01 裁决不再采用，一期序列化定稿 **JSON Schema**——见《[自定义表单功能详细设计](自定义表单功能详细设计.md)》§0.3 R01；配置页/编辑页/详情页落地为渲染器三形态（配置/编辑/详情），见同文档 §4。

2. 可支持的组件：
- 固定属性项：名称，id，是否必填（数据），说明文本（数据）、默认值（数据）

| 组件名称  | 类型 | 描述                                                  | 属性项                                                                  |
|-------| --- |-----------------------------------------------------|----------------------------------------------------------------------|
| 单行文本  | 数据 | 单行文本框                                               | 最大长度、是否密码                                                            |
| 多行文本  | 数据 | 多行文本框                                               | 最大长度                                                                 |
| 数字    | 数据 | 支持整数，小数，百分比，金额场景的输入                                 | 数字类型、精度、最大值、最小值、允许负数、分隔符（无、千分位、万分位、亿分位）等                             |
| 选择框   | 数据 | 选择框                                                 | 单多选、排列方式、选择项（显示值和实际值）                                                |
| 下拉选择器 | 数据 | 下拉选择框                                               | 单多选、选择项（显示值和实际值）                                                     |
| 日期    | 数据 | 日期选择器                                               | 类型（日期、时间、日期时间）、显示格式                                                  |
| 开关    | 数据 | switch 开关                                           | 【开】显示文本、【关】显示文本                                                      |
| 级联选择器 | 数据 | 根据父数据项的值决定选择器的可选值                                   | 父数据项（可选择已配置的数据类型组件）、选择项（公式（父数据项的公式判断，决定是否显示该选择项，一公式可配置多选择项）、显示值和实际值） |
| 公式计算  | 数据 | 配置中填写公式，计算结果                                        | 公式                                                                   |
| 数据源   | 数据 | 选择器组件                                               | 通过 sys-datasource 的数据源配置                                             |
| 地址本   | 数据 | 组织架构地址本组件                                           | 单多选、可选类型                                                             |
| 附件    | 数据 | 组件组件                                                | 数量上限、允许上传文件格式                                                        |
| ---   | --- | ---                                                 | ---                                                                  |
| 表格    | 内容 | table                                               |                                                                      |
| 明细表   | 内容 |                                                     |                                                                      |
| 文本    | 内容 |                                                     |                                                                      |
| 图片    | 内容 |                                                     |                                                                      |
| ---   | --- | ---                                                 | ---                                                                  |
| 权限组件  | 控制 | 1.8 BPM上需使用，结合流程配置，配置审批人、创建人、可阅读者，在审批、阅读时的字段可见，可编辑性 |                                                                      |

> 裁决标注（F15-DOC-001，2026-11-23）：见《[自定义表单功能详细设计](自定义表单功能详细设计.md)》§0.3 R01/R03——一期序列化定稿 **JSON Schema**（xml 表述不再采用）；一期组件基线 = 本文 12 数据 + 4 内容组件 + 布局组件（分组/栅格），人员类（员工/部门/岗位/角色）由地址本组件覆盖不单列、密码并入单行文本「是否密码」属性，权限组件一期仅预留协议位（运行时随 v1.8 BPM 消费）；地图/关联数据/自动编号/标签页/折叠面板/子表嵌套/自定义 Vue 组件/批量导入二期。组件全集定稿清单与属性项明细见功能详细设计 §1.3。
