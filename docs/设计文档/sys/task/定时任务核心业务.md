# 定时任务核心业务

## 权限

| 权限名 | 中文名 | 描述 |
| --- | --- | --- |
| SYS_TASK_ADMIN | 定时任务管理 | 拥有管理定时任务的权限 |

## 核心功能

### 定时任务接入

提供一个专有注解 `@SysTask`，该注解配置在类上，表示该类是一个定时任务类。

注解内要求参数包括：name, cron, params(字符串列表)；表示名称，cron表达式，填写参数列表三个信息；其中名称、cron 必填，参数默认为空列表；

定时任务类必须实现 execute(Map<String, String> params, Queue<String> logs) 方法，该方法是定时任务执行的调用方法，入参为配置参数和其值，以及将保存到 `sys_task_history.field_log` 的日志记录队列；

系统启动时，扫描所有类，将带有 `@SysTask` 注解的类写入 `sys_task_main` 表中，默认开启；

### 定时任务管理和执行

在 `后台管理` 中增加 `定时任务` 的二级菜单，仅限 `SYS_TASK_ADMIN` 权限的用户可访问；`定时任务` 下有两个页面：`定时任务管理` 和 `执行记录`

`定时任务管理`：列表页面，查询返回 `sys_task_main` 记录；

筛选区：名称、状态、是否启用

排序区：登记时间

按钮区：批量停用，批量启用

列表显示：任务名，cron表达式、是否启用、状态、登记时间、操作（启用/停用、编辑、执行）

`执行记录`：列表页面，查询返回 `sys_task_history` 记录：

筛选区：任务名称、结果、开始时间（范围）、结束时间（范围）

排序区：开始时间、结束时间

按钮区：无

列表显示：任务名、结果、开始时间、结束时间、操作（详情）

### 定时任务的编辑页面和启停用

1. 启用、停用按钮仅更新定时任务的"是否启用"状态

2. 在编辑页面，管理员可编辑维护 名称、cron表达式、参数列表值 三个字段；提交是检查cron表示是否合法；参数列表值在数据库中保存为 json 格式，所有值按字符串类型进行保存；

3. 在编辑页面上，根据 "状态" 字段的值，额外显示出 "中止当前任务" 按钮，执行后停止当前任务实例，当前任务按照 "失败" 结果被记录；
