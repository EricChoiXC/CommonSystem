# 组织架构接口清单

> 本文档描述组织架构（org）模块全部后端接口的路径、方法、请求/响应与鉴权，依据现有实现回写。
> 接口标识（action）常量定义于 `sys/org/properties` 各常量类，Controller 与 resolver 静态引用；
> 鉴权由各 Controller `authorize(action, documentId)` 兜底（未登录抛 `UNAUTHORIZED`、无权限抛 `FORBIDDEN`），
> `SYS_ADMIN` 经 `BaseResolver.hasAnyRole` 自动放行。
> 响应统一 `BaseResponse`；异常交 `GlobalExceptionHandler`。

## 组织架构元素维护（sys.org.element）

基础路径：`/backend/sys/org/element`

服务于组织架构管理页（`OrgManageView.vue`）：左侧树复用地址本 `tree` 接口（`orgTypes=[1,2]` 仅机构/部门），
右侧列表按点中节点的 `field_parent_id` 查询直接下级，支持筛选/排序/分页；创建/编辑按 `field_org_type`
写主表 `sys_org_element` 与对应扩展表（`sys_org_org` / `sys_org_dept` / `sys_org_user` / `sys_org_post`）。

| 接口标识 | 方法 | 路径 | 说明 | 鉴权 |
| --- | --- | --- | --- | --- |
| `sys.org.element.list` | POST | `/list` | 列表分页查询：请求体 `{ body: { parentId, fieldName, fieldCode, orgType, enable }, pages: { pageNo, pageSize, needPage }, sortField, sortOrder }`；`parentId` 为空查根级（`field_parent_id` 为空）；`sortField` 取 `createTime`/`updateTime`/`code`（默认创建时间降序），单条件排序；总数经 `metadata.total` 返回；人员 `field_login_name` 非管理员裁剪 | 已登录且账号启用（查询不设权） |
| `sys.org.element.load` | GET | `/load?fieldId=${id}` | 读取单条（含类型专有字段与父级/负责人名称） | 已登录且账号启用（读取不设权） |
| `sys.org.element.save` | POST | `/save` | 新增：名称/编码/类型必填；自动计算 `field_hierarchy`/`field_level`；人员密码必填且 BCrypt 加密入库 | SYS_ORG_ADMIN / SYS_ORG_ELEMENT_ADMIN / SYS_ORG_ELEMENT_ADD |
| `sys.org.element.update` | PATCH | `/update` | 编辑：父级变更时重算本节点与子树层级（`fieldParentId` null=保留原值、""=移根，防环）；密码不随本接口更新（仅通过 `sys.org.user.changePwd` 修改），请求携带的密码会被忽略 | SYS_ORG_ADMIN / SYS_ORG_ELEMENT_ADMIN / SYS_ORG_ELEMENT_EDIT |
| `sys.org.element.enable` | PATCH | `/enable` | 启停用：请求体 `{ fieldId, fieldEnable }`，仅更新启用状态与修改人/时间，不级联后代 | SYS_ORG_ADMIN / SYS_ORG_ELEMENT_ADMIN / SYS_ORG_ELEMENT_EDIT |
| `sys.org.element.delete` | DELETE | `/delete?fieldId=${id}` | 置为无效（物理删除主表 + 类型扩展表）：仅允许无直接下级节点 | SYS_ORG_ADMIN / SYS_ORG_ELEMENT_ADMIN / SYS_ORG_ELEMENT_ADD |

参数约定：

- `orgType`：组织架构类型数字（1=机构 2=部门 3=人员 4=岗位），为空表示全部；
- `enable`：启用状态布尔值，为空表示全部；
- `parentId`：上级组织架构元素 `fieldId`，为空表示根级（`field_parent_id` 为空）；
- 列表返回对象在公共字段基础上按类型归一化扩展字段（负责人、电话、邮箱、地址、性别、生日、登录名、在岗状态、账号状态），不返回任何密码字段。

## 用户维护（sys.org.user）

基础路径：`/backend/sys/org/user`

| 接口标识 | 方法 | 路径 | 说明 | 鉴权 |
| --- | --- | --- | --- | --- |
| `sys.org.user.login` | POST | `/login` | 登录：按登录名+密码校验（开启邮箱/电话登录时对应字段可登录），成功更新最后登录时间、签发会话 token（`metadata.X-Login-Token`）与 `forceChangePwd` 标记并返回用户（含 roles/auths/posts/virtuals，不含密码） | 无（登录前无身份） |
| `sys.org.user.logout` | POST | `/logout` | 登出：注销请求头 X-Login-Token 对应的会话，幂等 | 无（凭证即身份） |
| `sys.org.user.checkPwdChange` | GET | `/checkPwdChange` | 查询当前登录人是否需强制改密（定期改密周期），结果经 `metadata.forceChangePwd` 返回 | SYS_ORG_ADMIN / SYS_ORG_USER_MANAGER / 本人 |
| `sys.org.user.save` | POST | `/save` | 新增用户；登录名不可为邮箱/11 位手机号，电话/邮箱唯一；密码以 BCrypt 加密后入库 | SYS_ORG_ADMIN / SYS_ORG_USER_MANAGER |
| `sys.org.user.update` | PATCH | `/update` | 编辑用户；密码不随本接口更新（仅通过 `changePwd` 修改），请求携带的密码会被忽略 | SYS_ORG_ADMIN / SYS_ORG_USER_MANAGER / 本人 |
| `sys.org.user.changePwd` | PATCH | `/changePwd` | 请求体 `{ body: { fieldId, fieldPassword } }`；长度 6–32、不与最近 N 次历史重复；仅更新密码与最后修改密码时间（同步写 `sys_org_pwd_history`） | SYS_ORG_ADMIN / SYS_ORG_USER_MANAGER / 本人 |
| `sys.org.user.delete` | DELETE | `/delete?fieldId=${id}` | 删除用户（主表 + 人员扩展表） | SYS_ORG_ADMIN / SYS_ORG_USER_MANAGER |
| `sys.org.user.load` | GET | `/load?fieldId=${id}` | 读取单条，按可见性裁剪字段（`selectByIdWithFields`） | 登录用户 |
| `sys.org.user.list` | POST | `/list` | 列表查询，按可见性裁剪字段（`selectListWithFields`） | 登录用户 |
| `sys.org.user.export` | POST | `/export` | 导出（仅定义 `ACTION_EXPORT` 常量，控制器端点未实现，预留） | 预留 |
| `sys.org.user.import` | POST | `/import` | 导入（仅定义 `ACTION_IMPORT` 常量，控制器端点未实现，预留） | 预留 |

## 地址本选择（sys.org.addressbook）

基础路径：`/backend/sys/org/addressbook`

服务于地址本组件（`AddressBook.vue`）与组织架构管理页左侧树，仅查询 `sys_org_element` 主表，不承载写操作；结果只返回启用（`field_enable = 1`）节点。

| 接口标识 | 方法 | 路径 | 说明 | 鉴权 |
| --- | --- | --- | --- | --- |
| `sys.org.addressbook.tree` | POST | `/tree` | 树查询：请求体平铺 `{ orgTypes, limitRange, parentId }`；`parentId` 为空返回根级（`limitRange` 非空时以范围节点为根），否则返回该节点的直接下级；左侧树展开与右侧下级列表共用 | 已登录 |
| `sys.org.addressbook.list` | POST | `/list` | 关键字列表分页查询：请求体 `{ body: { keyword, orgTypes, limitRange }, pages: { pageNo, pageSize, needPage } }`，仅按关键字查询，总数经 `metadata.total` 返回 | 已登录 |
| `sys.org.addressbook.load` | POST | `/load` | 目标回填：请求体 `{ body: { ids: string[] } }`，按 id 列表读取名称等展示信息（仅回填已选值，不做类型/范围过滤） | 已登录 |

参数约定：

- `orgTypes`：组织架构类型数字数组（1=机构 2=部门 3=人员 4=岗位 5=角色 6=群组），为空表示不限制；
  其中 `tree` 固定追加 `field_org_type NOT IN (5, 6)`，角色与群组**不进入地址本树**（走专用页签）；`list` 保持通用，传 `orgTypes=[5]` 即返回角色分页；
- `limitRange`：限制的组织架构范围（元素 `fieldId` 值数组），为空表示不限制；树根节点以范围节点为根，列表/下级查询中「范围内」= 节点自身在范围内或其任一祖先在范围内（按 `field_hierarchy` 匹配）；
- 鉴权说明：地址本为只读查询，按「读取、查询组织架构元素不设权」的约定不限制角色，仅要求已登录且账号启用。

## 角色管理（sys.org.role）

基础路径：`/backend/sys/org/role`

服务于角色管理页（`RoleManageView.vue`）与角色新建/编辑页（`RoleFormView.vue`）。

| 接口标识 | 方法 | 路径 | 说明 | 鉴权 |
| --- | --- | --- | --- | --- |
| `sys.org.role.list` | POST | `/list` | 角色列表分页查询：请求体 `{ body: { fieldName, fieldCode, enable }, pages: { pageNo, pageSize, needPage }, sortField, sortOrder }`，总数经 `metadata.total` 返回；列表仅返回基本字段（含 `field_code`），无复选框列、禁止批量操作 | SYS_ORG_ADMIN / SYS_ORG_ROLE_ADMIN |
| `sys.org.role.load` | GET | `/load?fieldId=${id}` | 角色详情：基本字段 + 关联组织架构（`elementIds`/`elementNames`）+ 已选权限（`authIds`），供编辑页回显；不存在返回 `E_NOT_FOUND` | SYS_ORG_ADMIN / SYS_ORG_ROLE_ADMIN |
| `sys.org.role.save` | POST | `/save` | 新增角色：请求体为角色对象（含 `elementIds` / `authIds`），关联表全量写入；返回保存后的角色（含回填关联信息） | SYS_ORG_ADMIN / SYS_ORG_ROLE_ADMIN |
| `sys.org.role.update` | PATCH | `/update` | 编辑角色：请求体必须携带 `fieldId`，关联表先删后插全量替换；`field_code` 无条件赋值（允许清空） | SYS_ORG_ADMIN / SYS_ORG_ROLE_ADMIN |
| `sys.org.role.authOptions` | GET | `/authOptions` | 权限可选项：按 `sys_org_auth.field_model` 分组返回（分组标题取各模块 application.yml 的 `MODEL_NAME`），供角色表单权限分组 Card 复选 | SYS_ORG_ADMIN / SYS_ORG_ROLE_ADMIN |

说明：

- 角色删除、角色启停用接口当前未提供；角色的停用仅经编辑接口改 `field_enable`；
- 内置系统管理员角色（`field_id = 32 个 '0'`）由启动任务幂等维护，不经本组接口管理。

## 权限预览（sys.org.preview）

基础路径：`/backend/sys/org/preview`

服务于权限预览页（`RolePreviewView.vue`）：按用户节点递归展开其角色与权限来源。

| 接口标识 | 方法 | 路径 | 说明 | 鉴权 |
| --- | --- | --- | --- | --- |
| `sys.org.preview.preview` | POST | `/preview` | 权限预览：请求体 `{ elementId }`；返回该组织架构元素（应为人员且非虚拟）的 `{ element, relatedOrgs, roles, auths }`——组织架构名称、关联组织架构（`sys_org_role_element`）、角色列表（四来源汇总，见核心业务设计）、权限列表（角色绑定权限汇总） | SYS_ORG_ADMIN / SYS_ORG_ROLE_ADMIN |
| `sys.org.preview.treeChildren` | POST | `/treeChildren` | 权限树子节点：请求体 `{ type, id }`；`type` 取 `element`/`role`/`auth`——element 展开直接关联角色、直属上级组织架构与直接关联虚拟组织，role 展开直接绑定权限，auth 为叶子；节点返回 `{ type, id, name, prefix }` | SYS_ORG_ADMIN / SYS_ORG_ROLE_ADMIN |

说明：

- 仅人员（`field_org_type = 3`）且非虚拟组织节点支持预览，其他节点由前端拦截不发起请求；
- 虚拟组织不展开上级组织架构（防 虚拟 ↔ 上级 互相引用成环）。

## 通用约定

- 列表请求体 `{ body, pages: { pageNo, pageSize, needPage } }`，总数经 `metadata.total` 返回；
- 单 `id` 或无参用 `GET`；含非 `id` 条件用 `POST`；更新只用 `PATCH`（禁 `PUT`）；删除用 `DELETE`；
- 登录会话经请求头 `X-Login-Token` 携带（`api/index.js` 拦截器统一注入），TTL 8 小时。
