# 组织架构核心业务设计

## 权限

| 权限名 | 中文名       | 描述                   |
| --- |-----------|----------------------|
| SYS_ORG_ADMIN | 组织架构模块管理员 | 组织架构模块管理员，拥有该模块下所有权限 |
| SYS_ORG_ELEMENT_ADMIN | 组织架构管理员 | 拥有所有 `SYS_ORG_ELEMENT_*` 权限 |
| SYS_ORG_ELEMENT_ADD | 组织架构添加权限 | 添加组织架构元素 |
| SYS_ORG_ELEMENT_EDIT | 组织架构编辑权限 | 修改组织架构元素 |
| SYS_ORG_ROLE_ADMIN | 权限管理员 | 拥有权限、角色管理权限 |
| SYS_ORG_USER_MANAGER | 人员维护者 | 可维护人员信息与修改密码 |

## 核心功能

### 组织架构

#### 创建组织架构元素

拥有 `SYS_ORG_ELEMENT_ADMIN` 权限的用户可以进行组织架构元素的创建；

创建时，需要指定组织架构元素的组织架构类型和是否虚拟组织架构，两者不存在冲突；

根据选择的组织架构类型，在页面上提供公共字段填写和类型专有字段填写，其中部分字段仅在 "是虚拟组织"或"非虚拟组织" 下才允许填写：

| 字段名                | 描述 | 是否必填                 | 默认值                           | 所属         | 是非虚拟组织填写 |
|--------------------| --- |----------------------|-------------------------------|------------|----------|
| field_name         | 名称 | 是                    | ``                            | 公共字段       | 无        |
| field_code         | 编码 | 是                    | ``                            | 公共字段       | 无        |
| field_parent       | 上级组织架构元素 | 否 | 根据进入新建页面时的树形地址本选中项决定 | 公共字段       | 无        |
| field_type         | 组织架构类型 | 是                    | 根据进入新建页面时查询列表的查询条件决定，无时默认`机构` | 公共字段       | 无        |
| field_is_virtual   | 是否虚拟组织 | 是                    | `否`                           | 公共字段       | 无        |
| field_leader       | 组织架构负责人 | 否                    | ``                            | 机构、部门、岗位字段 | 非        |
| field_manager      | 组织架构管理员 | 否                    | ``                            | 机构、部门、岗位字段 | 非        |
| field_phone        | 联系电话 | 否                    | ``                            | 机构、部门、人员字段 | 非        |
| field_email        | 联系邮箱 | 否                    | ``                            | 机构、人员字段    | 非        |
| field_address      | 联系地址 | 否                    | ``                            | 机构、部门、人员字段 | 非        |
| field_gender       | 性别 | 是                    | `男`                           | 人员字段       | 非        |
| field_birthday     | 生日 | 否                    | ``                            | 人员字段       | 非        |
| field_login_name   | 登录名 | 是                    | ``                            | 人员字段       | 无        |
| field_password     | 密码 | 是                    | ``                            | 人员字段       | 无        |
| field_job_status   | 在岗态 | 是                    | `在岗`                          | 人员字段       | 非        |
| field_post_user | 岗位人员 | 否 | `` | 岗位字段       | 非        |
| field_virtual_user | 虚拟组织机构关联用户 | 否 | ``                            | 机构、部门、岗位字段 | 是        |

上级组织架构元素的可选范围仅限非虚拟组织的机构或部门；

#### 编辑组织架构元素

拥有 `SYS_ORG_ELEMENT_EDIT` 权限 或 用户本人 可进行组织架构元素的编辑维护；

对 用户 的维护范围视维护人而定：

> 用户本人：仅允许维护 联系电话、联系邮箱、联系地址、性别、生日；
> 权限用户：可允许维护所有可填写字段

> 人员的密码不在编辑表单中维护（前端编辑/查看页通过按钮区「修改密码」弹窗修改，走 `changePwd` 接口）。

#### 密码安全

- `field_password`（密码）在创建用户时必填，以 **BCrypt 单向加密**（自带随机盐、不可逆）后入库，明文不落库；
- 任何查询（load / list / 导出）的列集合都不返回密码字段；
- 修改密码走 `changePwd` 接口（`PATCH /backend/sys/org/user/changePwd`），仅更新 `field_password` 与 `field_last_chg_pwd_time`，不影响用户其他字段；
- `changePwd` 鉴权与编辑一致：`SYS_ORG_ADMIN`、`SYS_ORG_USER_MANAGER` 或 用户本人；
- 编辑/更新接口（`sys.org.element.update`、`sys.org.user.update`）不接受密码字段，请求携带的密码会被忽略——密码仅通过 `changePwd` 接口修改。

#### 读取，查询组织架构元素

不设权，仅对 用户 数据做可读信息限制

> 用户本人、权限用户：除密码不限制；
> 非本人、非权限用户：登录名、密码不可见；联系电话、联系邮箱、联系地址做脱敏处理；
> 权限用户：包含 `SYS_ORG_ELEMENT_*` 下任一权限，或该用户在用户的直属组织架构链路上的机构/部门的机构负责人和机构管理员

### 权限与角色

#### 创建与维护角色

拥有 `SYS_ORG_ROLE_ADMIN` 权限的用户可创建或编辑角色

编辑信息：

| 字段名 | 描述     | 是否必填 |
| --- |--------|------|
| field_name | 角色名称   | 是    |
| field_enable | 角色是否启用 | 是    |
| field_description | 权限描述   | 否    |
| auths | 权限列表   | 否    |
| elements | 组织架构列表 | 否    |

#### 权限计算

从用户为起点，包含所属岗位、所属虚拟组织架构；在其直属组织架构链路上的组织架构，拥有的角色和权限的集合，即为用户的权限集合；
