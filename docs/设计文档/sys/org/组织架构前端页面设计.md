# 组织架构前端页面设计

> 本文档承接组织架构管理页（`/org`，`OrgManageView.vue`）的前端页面设计。
> 后端接口约定见 [组织架构接口清单.md](./组织架构接口清单.md)，数据结构见 [组织架构表结构.md](./组织架构表结构.md)。

## 1. 页面目标与入口

- 页面名称：组织架构管理页（列表/树页）+ 新建/编辑页 + 详情页
- 路由（菜单归属「组织架构」一级菜单下的「当前组织架构」，新建/编辑/查看页均显示顶部标签卡片）：
  - `/org`：组织架构管理列表页（`OrgManageView.vue`）
  - `/org/create`：新建页（`OrgFormView.vue` 新建模式），按路径建单卡片
  - `/org/edit/:id`：编辑页（`OrgFormView.vue` 编辑模式，按对象 id 加载）；动态路由按路由 name 复用单个标签卡片，卡片 path 跟随最新对象，避免按 id 无限堆积标签
  - `/org/detail/:id`：详情页（`OrgDetailView.vue`，按对象 id 加载）；同上按 name 复用单卡片
- 页面类型：列表/树页（左右双栏）+ 独立表单页 + 独立详情页
- 主要角色：组织架构管理员、组织架构维护者
- 页面目标：维护组织架构树及节点基础信息，支持机构/部门/人员/岗位四类节点的查询、创建、编辑、启停用与置为无效

## 2. 页面布局

```text
┌──────────────────────────┬────┬──────────────────────────────────────────────┐
│     左侧：组织架构树        │ 拖 │  筛选条件区（四分栅栏：名称 | 编号 | 类型 | 启用状态） │
│   ▸ 根节点                │ 拽 │──────────────────────────────────────────────│
│     ▸ 机构A               │ 条 │  排序区（创建时间/更新时间/编码）│ 按钮区（查询/创建/置为无效） │
│       ▸ 部门A-1           │    │──────────────────────────────────────────────│
│       ▸ 部门A-2           │    │  分页查询结果列表（首列复选框，末列：详情/编辑/停用启用）      │
│     ▸ 机构B               │    │                                              │
└──────────────────────────┴────┴──────────────────────────────────────────────┘
```

- 默认 25% : 75% 左右分栏，中间拖拽条可手动调整占比（限制 15% ~ 40%）。
- 右侧区域自上而下：筛选条件区 → 排序区/按钮区 → 分页结果列表。

## 3. 左侧树

- 以「根节点」为树头虚拟入口（`__root__`），懒加载展开。
- 树节点仅查询机构（`field_org_type = 1`）与部门（`field_org_type = 2`）两类节点，调用
  `POST /backend/sys/org/addressbook/tree`（`orgTypes: [1, 2]`）。
- 节点前置图标区分类型：机构使用办公建筑图标（橙），部门使用学校图标（绿），根节点使用首页图标（蓝）。
- 默认展开「根节点」并点中它；点击任意节点后，右侧列表切换为查询该节点的直接下级
  （根节点 → `field_parent_id` 为空）。

## 4. 右侧列表区

### 4.1 筛选条件区

四分栅栏排列（`el-row` + `el-col :span="6"`）：

| 字段 | 控件 | 默认值 |
| --- | --- | --- |
| 名称 | 文本输入（模糊匹配） | 空 |
| 编号 | 文本输入（模糊匹配） | 空 |
| 类型 | 下拉：机构/部门/人员/岗位（无「全部」项） | 人员 |
| 启用状态 | 下拉：全部/启用/停用 | 启用 |

### 4.2 排序区与按钮区

- 排序区提供三个可排序字段：创建时间、更新时间、编码；仅允许单条件排序。
- 默认选中「创建时间 + 降序」；点击已选中字段切换升/降序，点击未选中字段选中并默认降序。
- 选中项样式：外框 + 文本结尾上下箭头（↓ 降序 / ↑ 升序）；未选中项无外框。
- 按钮区：查询（按当前筛选/排序刷新）、创建（跳转 `/org/create`，携带当前点中节点作为默认上级）、置为无效（对勾选行批量删除，二次确认）。
- 按钮区权限显隐（前端按登录用户权限码预判，最终由后端 `ElementResolver` 兜底）：创建、置为无效按钮需 `SYS_ORG_ADMIN` / `SYS_ORG_ELEMENT_ADMIN` / `SYS_ORG_ELEMENT_ADD`（系统管理员 `SYS_ADMIN` 自动放行）任一权限才显示；查询按钮所有登录用户可见。

### 4.3 分页结果列表

- 首列为复选框列，末列为操作列（详情 / 编辑 / 停用或启用），不展示任何 id 字段。
- 列表列根据查询类型动态展示：

| 查询类型 | 列表字段 |
| --- | --- |
| 机构 | 名称、编码、负责人、联系电话、联系邮箱、联系地址、状态、创建时间 |
| 部门 | 名称、编码、负责人、联系电话、联系地址、状态、创建时间 |
| 人员 | 姓名、工号、登录名、性别、联系电话、联系邮箱、状态、创建时间 |
| 岗位 | 名称、编码、状态、创建时间 |

- 类型筛选无「全部」项（枚举必选），列表列固定按当前筛选类型展示。

- 操作列按钮：详情（跳转 `/org/detail/:id`）、编辑（跳转 `/org/edit/:id`）、停用/启用（二次确认，行内切换）。
- 操作列权限显隐（前端按登录用户权限码预判，最终由后端 `ElementResolver` 兜底）：编辑、停用/启用按钮需 `SYS_ORG_ADMIN` / `SYS_ORG_ELEMENT_ADMIN` / `SYS_ORG_ELEMENT_EDIT`（系统管理员 `SYS_ADMIN` 自动放行）任一权限才显示；无编辑权限时操作列仅显示详情。
- 分页组件：`total, prev, pager, next, sizes`，页大小 10/20/50/100。

## 5. 新建 / 编辑页（独立路由，`OrgFormView.vue`）

- 页面宽度 100%；表单字段名与字段值按 2:3 固定比例排版（`label-width="40%"`，两列栅格布局下每个字段行内 label 占 40%、内容占 60%）。

- 新建模式（`/org/create`）：打开时先调用 `GET /backend/common/initID` 预取 32 位对象 ID 赋给 `fieldId`（遵循 docs/开发规范.md 第 9 节）；默认上级/类型取自列表页路由 query（`parentId`/`parentName`/`orgType`），缺省根节点 + 机构。
- 编辑模式（`/org/edit/:id`）：按路由 id 调用 `GET /backend/sys/org/element/load` 回填表单；保存调用 `PATCH /update`。
- 保存成功后返回 `/org` 列表页；新建/编辑共用同一表单组件，按路由区分模式。
- 公共字段：名称（必填）、编码（必填）、类型（新建可选、编辑禁用）、上级（地址本选择，仅机构/部门）、是否虚拟组织、启用状态。
- 机构专有字段：负责人（地址本选人员）、联系电话、联系邮箱、联系地址。
- 部门专有字段：负责人、联系电话、联系地址。
- 人员专有字段：登录名（必填）、密码（新建必填；编辑/查看页不在表单维护密码，通过按钮区「修改密码」弹窗修改）、性别（默认男）、生日、在岗状态（默认在职）、联系电话、联系邮箱、联系地址。
- 编辑模式按钮区（返回 + 修改密码 + 保存）：当编辑对象为人员（类型=3）且当前用户具备修改密码权限（`SYS_ORG_ADMIN` / `SYS_ORG_USER_MANAGER`，或为本人）时，显示「修改密码」按钮；点击弹出修改密码弹窗（输入新密码 + 二次确认，两值一致且非空校验），提交调用 `PATCH /backend/sys/org/user/changePwd`，成功后关闭弹窗并提示。
- 保存按钮权限显隐：新建模式需 `SYS_ORG_ADMIN` / `SYS_ORG_ELEMENT_ADMIN` / `SYS_ORG_ELEMENT_ADD`（系统管理员 `SYS_ADMIN` 自动放行）任一权限才显示；编辑模式需 `SYS_ORG_ADMIN` / `SYS_ORG_ELEMENT_ADMIN` / `SYS_ORG_ELEMENT_EDIT` 任一权限才显示。无保存权限时按钮区仅剩返回（及可用的修改密码），最终由后端 `ElementResolver` 兜底。
- 新建模式按钮区（返回 + 保存）：不提供修改密码（新建时通过表单密码字段设置初始密码）。
- 岗位专有字段：负责人。

## 6. 详情页（独立路由，`OrgDetailView.vue`）

- 路由 `/org/detail/:id`，按 id 调用 `GET /backend/sys/org/element/load` 加载后只读展示，页面提供「返回」「编辑」按钮（编辑跳转 `/org/edit/:id`）。
- 「编辑」按钮权限显隐：需 `SYS_ORG_ADMIN` / `SYS_ORG_ELEMENT_ADMIN` / `SYS_ORG_ELEMENT_EDIT`（系统管理员 `SYS_ADMIN` 自动放行）任一权限才显示；无编辑权限时按钮区仅剩返回（及可用的修改密码），最终由后端 `ElementResolver` 兜底。
- 按钮区：当详情对象为人员（类型=3）且当前用户具备修改密码权限（`SYS_ORG_ADMIN` / `SYS_ORG_USER_MANAGER`，或为本人）时，额外提供「修改密码」按钮；点击弹出修改密码弹窗（输入新密码 + 二次确认，校验同编辑页），提交调用 `PATCH /backend/sys/org/user/changePwd`。
- 排版与新建/编辑页保持一致：默认一行两字段，字段名:字段值 = 2:3（label 40% / 内容 60%）；长内容字段（联系地址）一行一字段，字段名:字段值 = 2:8（label 20% / 内容 80%）。
- 实现方式：自定义 flex 网格（`.detail-grid`），不使用 `el-descriptions`（其非垂直模式单元格 colspan 恒为 1，无法实现长字段整行 2:8 布局）。
- 按节点类型动态组装字段：公共字段名称、编码、类型、上级、是否虚拟、启用状态、创建时间、更新时间；机构/部门/岗位展示负责人；机构/部门/人员展示联系电话、联系地址（长字段）；机构/人员展示联系邮箱；人员额外展示登录名、性别、生日、在岗状态。

## 7. 接口依赖

| 用途 | 接口 | 说明 |
| --- | --- | --- |
| 左侧树 | `POST /backend/sys/org/addressbook/tree` | `orgTypes: [1, 2]`，机构/部门节点 |
| 右侧列表 | `POST /backend/sys/org/element/list` | `parentId` 为空查根级；支持筛选/排序/分页 |
| 详情 | `GET /backend/sys/org/element/load?fieldId=` | 单条读取 |
| 创建 | `POST /backend/sys/org/element/save` | 写主表 + 类型扩展表 |
| 编辑 | `PATCH /backend/sys/org/element/update` | 写主表 + 类型扩展表 |
| 启停用 | `PATCH /backend/sys/org/element/enable` | 仅更新启用状态 |
| 置为无效 | `DELETE /backend/sys/org/element/delete?fieldId=` | 仅允许无直接下级节点 |

## 8. 待确认事项

- 「置为无效」当前按物理删除实现（删除主表 + 扩展表）；如后续需要软删除/作废标记，需同步调整后端实现与表结构。
- 人员列表「登录名」对非管理员不可见（后端裁剪）；是否需要在详情页补充权限提示待确认。
- 树结构变更（创建/编辑/删除）后当前采用整树重新挂载刷新，若节点层级很深可优化为局部刷新。
