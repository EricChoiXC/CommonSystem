## 一、背景与范围

为 CommonSystem 公共模块工程新增多语言管理能力，模块包路径 `com.common.system.sys.i18n`，覆盖：

- 语言管理：初始仅【中文 zh_CN】（默认）与【英文 en_US】，管理员后续自行维护；
- 资源管理：i18n 资源仅经 `/resource/i18n/`（实施取 `resources/i18n/`）及其子文件夹管理，子文件夹层级名即 `field_model`；启动时读取 `application.properties` 作为资源与中文翻译，`application_${language_code}.properties` 作为其他语言翻译；
- 翻译管理：网页维护（选模块 → 矩阵编辑 → 二次确认提交 / 重置）、批量导入导出、单条重置；
- 系统运转：部署按钮（资源 → DB → 前端语言包 + 后端缓存）、前端 vue-i18n、后端 i18n 服务类；
- 用户语言：登录页选择语言并登记用户语言表；顶部栏切换仅切换页面语言、不落库。

权限：`SYS_I18N_ADMIN`（多语言管理员）执行全部维护操作；普通用户不可访问多语言维护模块。

## 四、数据模型设计

四张表均遵循 `field_` 前缀 + `field_id VARCHAR(32)` 规范（`sys_i18n_user_language` 以 `field_user_id` 为主键，一人一条；实体仍继承 `BaseModel` 以满足 Dao/Mapper 泛型约束，不映射公共 `field_id`）。

| 表 | 语义 | 关键设计点 |
| --- | --- | --- |
| `sys_i18n_language` | 语言清单 | `field_code VARCHAR(20)` 建索引；`field_default BIT` 全局仅一条（切换默认语言需互斥更新：先清后设）；`field_order INT` 决定翻译矩阵语言列顺序。启动任务保证 zh_CN（默认、order 1）与 en_US（order 2）存在 |
| `sys_i18n_key` | 资源登记 | `(field_model, field_key)` 联合索引；key 仅由资源文件扫描产生，**不提供人工新增 / 删除入口**（D5 已确认，见「二」） |
| `sys_i18n_translation` | 翻译文本 | `(field_key, field_language)` 业务唯一（代码层保证，不建唯一约束以便重置删插）；**`field_update_time` 是「人工编辑过」标记**：非空=管理员改过（启动/部署同步不覆盖），空=来自资源文件（可被覆盖）。整个覆盖机制围绕该字段。`field_message TEXT` |
| `sys_i18n_user_language` | 用户默认语言 | 登录时 upsert（`field_user_id` 主键，存在更新、不存在插入）；顶部栏切换不写此表。删除语言时已选该语言的登记改绑当前默认语言（D4，不删行） |

DDL 定稿见附录 A（迁移脚本 `V1_01_040__sys_i18n_schema.sql`，实施时直接采用；列名与附录 A 不一致时以文档先改为准）。

## 五、核心机制设计

### 5.1 启动同步（需求 4、5；追加到 SysStartupTask#run 第 8 个任务）

1. 保证初始语言：`sys_i18n_language` 无记录时插入 zh_CN（默认）+ en_US；已初始化后不重复处理（管理员维护优先）；
2. 扫描 `classpath*:i18n/**/application.properties` → `field_model` = 子目录层级相对路径；key 登记 `sys_i18n_key`；value 作为中文翻译写入 zh_CN 记录（`field_update_time` 置空）；
3. 扫描 `i18n/**/application_${language_code}.properties`，按启用语言写入对应翻译；
4. **覆盖规则**：翻译已存在时仅 `field_update_time IS NULL` 的记录用资源文件值覆盖；非空（人工编辑过）跳过；缺失的新增。
5. 同步完成后刷新后端缓存（5.5）。

实现注意：properties 文件含中文时须以 UTF-8 读取（`new InputStreamReader(in, StandardCharsets.UTF_8)` + `Properties.load(Reader)`，JDK 9+ 支持），不可用默认 ISO-8859-1 的 `load(InputStream)`。

### 5.2 翻译网页维护（需求 6.1）

- 模块下拉：后端聚合 `sys_i18n_key` 去重 `field_model` + 既有 `properties/**/application.yml` 的 `MODEL_NAME` 显示名（`i18n/{model}` 与 `properties/{...}/{model}` 按末段路径匹配；注意 `MODEL_KEY` 形如 `SYS-ORG` 与 `field_model=org` 不同源，不能直接相等匹配）；取不到回退 `field_model`；单选；
- 矩阵：行 = 资源（`field_key` 升序），列 = 启用语言按 `field_order` 升序；资源列 `fixed="left"`，语言列超宽出横向滚动条（el-table 原生）；
- 编辑：明细表内直接编辑（`el-input`）；提交时前端 diff「加载快照 vs 当前值」，弹窗列出改动项二次确认，确认后批量提交；「重置」按钮还原为加载时快照（仅还原本次未提交的编辑）；
- 保存时后端对每条变更记录 `field_update_time = now`。

### 5.3 导入 / 导出（需求 6.2）

- 导出：所选模块全量（EasyExcel：列 = 资源名 + 按 field_order 排序的各语言）；
- 导入：固定覆盖导入——仅按上传文件中实际包含的 (key, language) 更新翻译；文件中出现但 `sys_i18n_key` 未登记的 key、或无效语言码的列一律跳过，**不插入资源项**；导入的记录视为人工编辑（写 `field_update_time`）。

### 5.4 重置（需求 6.3）

「操作」列仅「重置」按钮（按资源行 × 语言生效），二次确认后：
1. 清空该翻译记录 `field_update_time`；
2. 从资源文件读取该 key 当前值覆盖保存；
3. 若该语言在资源目录无对应配置文件（或该文件中无此 key）→ 直接删除该翻译记录。

### 5.5 部署（需求 7）

「语言管理-部署」页面仅一个部署按钮（`SYS_I18N_ADMIN`），动作 = 手动触发与启动同规则的「资源 → DB 同步」→ 生成前端语言包 → 刷新后端缓存：

- 后端：翻译载入内存 Map（language → key → message）+ Redis Hash（key 形如 `i18n:message:map:{language}`），Redis 不可用时本地兜底（照 `ModelCacheService` 模式）；提供 `I18nService.message(String key, String language, String... args)` 供各模块服务类读取（缺语言回退默认语言，缺 key 回退 key 本身）；
- 前端：`GET /locales/{code}.json` 动态输出该启用语言全量翻译（`vue-i18n` 动态 `setLocaleMessage` 加载）；部署后前端下次拉取即新值。

### 5.6 用户语言（需求 8）

- 登录页语言下拉（免鉴权接口取启用语言列表，默认语言置顶/默认选中）；登录请求 body 携带 `fieldLanguage`，登录成功后 upsert `sys_i18n_user_language`；
- 顶部菜单栏右侧新增语言切换下拉：切换后立即切换页面语言（vue-i18n locale + localStorage 记忆 + Element Plus `el-config-provider` locale 联动），**不写用户语言表**。

## 六、接口清单（已冻结）

路径遵循 `/backend/sys/i18n/{次级}/{方法}`；均需 `ACTION_*` 常量（模块 `properties` 常量类，如 `SysI18nConstants`）+ `I18nResolver` 分支；`@Operation.description` 以「鉴权动作 …」开头。

| 接口 | 方法 | 鉴权 |
| --- | --- | --- |
| `/backend/sys/i18n/language/list` | GET | 免鉴权（登录页下拉需要，`@SecurityRequirements` 标注无安全要求） |
| `/backend/sys/i18n/language/save` | POST | `SYS_I18N_ADMIN` |
| `/backend/sys/i18n/language/update` | PATCH | `SYS_I18N_ADMIN` |
| `/backend/sys/i18n/language/delete?fieldId=` | DELETE | `SYS_I18N_ADMIN`（级联策略 D4 已确认：删翻译 + 用户语言登记改绑默认语言） |
| `/backend/sys/i18n/language/setDefault` | PATCH | `SYS_I18N_ADMIN`（互斥切换） |
| `/backend/sys/i18n/model/list` | GET | 登录即可 |
| `/backend/sys/i18n/translation/list` | POST | `SYS_I18N_ADMIN`（body 含 fieldModel） |
| `/backend/sys/i18n/translation/update`（批量） | PATCH | `SYS_I18N_ADMIN` |
| `/backend/sys/i18n/translation/reset` | PATCH | `SYS_I18N_ADMIN`（key + language） |
| `/backend/sys/i18n/translation/export` | POST | `SYS_I18N_ADMIN`（文件流） |
| `/backend/sys/i18n/translation/import` | POST | `SYS_I18N_ADMIN`（multipart） |
| `/backend/sys/i18n/deploy/run` | POST | `SYS_I18N_ADMIN` |
| `/locales/{code}.json` | GET | 免鉴权（前端语言包） |
| `/backend/sys/i18n/user/language/update` | PATCH | 登录即可 |

前端菜单（HomeView）：`系统管理` 下新增分组「多语言管理」：`语言管理`、`翻译维护`、`部署`，均 `auth: 'SYS_I18N_ADMIN'`；`activeMenu` 补前缀归约；路由 `meta.auth` 同步。

## 七、前端设计要点

- 新增依赖：`vue-i18n@11`（Vue 3 配套版本）；Element Plus locale 经 `el-config-provider` 动态绑定；
- 基建：`src/locales/`（vue-i18n 实例 + 加载器）、`src/stores/language.js`（当前语言 + 已加载语言包缓存）、`src/api/i18n.js`；
- 语言包加载：启动时按 localStorage 记忆语言（无则默认 zh_CN）调 `/locales/{code}.json`；切换语言时懒加载对应包；
- 页面（`系统管理` 下新增「多语言管理」分组，均 `auth: 'SYS_I18N_ADMIN'`）：
  - **语言管理**（`/i18nLanguage`）：标准三段式列表页（筛选区：名称/编号/启用状态；工具区：创建按钮；列表区：语言码、名称、启用、默认、排序号；操作列：启停用、编辑、设默认、删除，启停用/删除/设默认二次确认）。语言仅 5 个字段，建议新建/编辑用弹窗（免增子路由；若按工程惯例走独立 FormView 则补 `meta.tab: 'name'` 与 `activeMenu` 归约）；
  - **翻译维护**（`/i18nTranslation`）：模块单选下拉 → 矩阵表格（资源列 `fixed="left"`，语言列按 `field_order` 升序、超宽出横向滚动条）→ 单元格内直接编辑 → 提交时弹窗二次确认（仅列出本次改动项）/「重置」按钮还原为加载快照；工具区「导出」（该模块全量 EasyExcel）与「导入」（上传 `.xlsx`，覆盖导入）按钮；
  - **部署**（`/i18nDeploy`）：页面仅一个「部署」按钮，点击执行部署并展示结果（同步资源数、各语言包生成情况）；
- 登录页：新增语言下拉（数据来自免鉴权语言列表接口，默认语言默认选中）；登录成功把所选语言码随 body 提交；
- 顶部栏：右侧（铃铛/日程旁）新增语言切换下拉，切换即更新 vue-i18n locale + Element Plus locale + localStorage 记忆，不调用户语言接口；
- 路由与菜单：三路由登记 `meta.title` / `meta.auth`；`HomeView.menus` 补「多语言管理」分组（分组 `auth: 'SYS_I18N_ADMIN'`，子项 `auth: ''` 随分组）；三个页面均为叶子路径、无子路由，`activeMenu` 暂无前缀归约需求（后续若语言管理改独立表单页再补）。

## 附录 A：迁移脚本草案（V1_01_040__sys_i18n_schema.sql）

```sql
-- 语言表
CREATE TABLE IF NOT EXISTS sys_i18n_language (
    field_id       VARCHAR(32)  NOT NULL COMMENT 'id',
    field_code     VARCHAR(20)  NOT NULL COMMENT '语言码（如 zh_CN、en_US）',
    field_name     VARCHAR(200) NOT NULL COMMENT '名称（如 中文、English）',
    field_enable   BIT(1)       NOT NULL DEFAULT b'1' COMMENT '是否启用',
    field_default  BIT(1)       NOT NULL DEFAULT b'0' COMMENT '是否默认语言（系统默认中文 zh_CN）',
    field_order    INT          NOT NULL DEFAULT 0 COMMENT '排序号',
    PRIMARY KEY (field_id),
    KEY idx_i18n_language_code (field_code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='多语言-语言表';

-- 资源表
CREATE TABLE IF NOT EXISTS sys_i18n_key (
    field_id       VARCHAR(32)  NOT NULL COMMENT 'id',
    field_key      VARCHAR(200) NOT NULL COMMENT '关键字（资源 properties 的键）',
    field_model    VARCHAR(200) NOT NULL COMMENT '所属模块（资源子文件夹层级名，如 org、process/template）',
    PRIMARY KEY (field_id),
    KEY idx_i18n_key_model_key (field_model, field_key)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='多语言-资源表';

-- 翻译表（(field_key, field_language) 业务唯一由代码层保证、不建唯一约束，便于重置删插；
-- field_update_time 非空=人工已编辑，启动/部署同步不覆盖）
CREATE TABLE IF NOT EXISTS sys_i18n_translation (
    field_id            VARCHAR(32)  NOT NULL COMMENT 'id',
    field_key           VARCHAR(200) NOT NULL COMMENT '关键字（sys_i18n_key.field_key）',
    field_language      VARCHAR(20)  NOT NULL COMMENT '语言码（sys_i18n_language.field_code）',
    field_message       TEXT                  COMMENT '翻译文本',
    field_update_time   DATETIME              COMMENT '更新时间（非空=人工已编辑，启动同步不覆盖；为空=资源文件导入）',
    PRIMARY KEY (field_id),
    KEY idx_i18n_translation_key_language (field_key, field_language)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='多语言-翻译表';

-- 用户语言表（一人一条，field_user_id 为主键）
CREATE TABLE IF NOT EXISTS sys_i18n_user_language (
    field_user_id     VARCHAR(32) NOT NULL COMMENT '用户id（sys_org_user.field_id）',
    field_language_id VARCHAR(32) NOT NULL COMMENT '语言id（sys_i18n_language.field_id）',
    PRIMARY KEY (field_user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='多语言-用户语言表';
```
