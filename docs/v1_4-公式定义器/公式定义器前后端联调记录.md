| 项 | 内容 |
| --- | --- |
| 现象（修复前实测） | 保存成功后列表行「变量依赖数」列显示 **0**，而该公式实际依赖 2 个变量（applyAmount/taxRate）；详情页（load 通道）计数正确显示 2 |

| 修复 | `FormulaManageView.vue#dependencyCount`：兼容数组与 JSON 字符串两种形态（字符串先 `JSON.parse` 再取长度，解析失败/空/缺失均回退 0），注释同步说明双形态承载口径；仅改该函数及其注释，不改模板结构与其它逻辑 |
