### 1.2 当前版本范围

- 版本目标：交付公共表达式服务——AviatorScript 引擎封装（沙箱 + 资源限制）+ 九类内置函数与 SPI 函数注册中心 + 组件四接口（options/functions/validate/simulate，登录即可）+ 命名公式管理（`sys_formula` 单表 + 6 管理接口 + 管理页）+ FormulaDesigner 公式弹窗组件；为 v1.5 自定义表单、v1.7 流程管理改造、v1.9 消息通知提供前置公共能力。
- In Scope：
  - `backend/pom.xml` 新增 AviatorScript 依赖（版本以 pom 实装为准）；
  - `sys_formula` 建表（实体注解声明，经注解同步引擎建表，不新增迁移脚本——Flyway 已移除，见 `../v1_3-数据源/1_3_2-注解维护表结构替换flyway/`）；
  - 模块骨架：常量/枚举/SPI/Registry/engine（含内置函数）/Service/Resolver/Controller/Mapper/`roles.yml`/`moduleGroup.yml`；
  - 10 个接口：list/load/save/update/enable/delete/options/functions/validate/simulate，错误码 `CS_FORMULA_*` 9 类；
  - 内置函数九类首批（MATH/LOGIC/COMPARE/STRING/DATE/COLLECTION/CONVERT/SYSTEM/DATA，`DS_QUERY` 委托数据源统一执行入口）；
  - 前端：`api/formula.js`、`components/formula/FormulaDesigner.vue` 公共弹窗组件、管理页（列表/表单/详情）、路由与菜单、`views/ui.vue` 样例登记。
- Out of Scope（方案 §9 明确不做 / 后续演进）：公式间联动重算（拓扑排序、循环检测，随 v1.5）、明细表行内计算（随 v1.5）、org 取值函数 `ORG_*`（随 v1.7）、流程触发条件迁移统一公式（随 v1.7）、公式版本管理（三期）、执行日志（三期）、自定义函数管理界面（三期评估）、前端独立解析引擎 Math.js（不排期）。
- 影响范围：`backend/src/main/java/com/eric/base/sys/formula/`、`backend/src/main/resources/{mappers,properties}/`、`backend/pom.xml`、`backend/src/test/java/`、`frontend/src/{api,components,views,router}/`、`frontend/package.json`、`docs/`。

### 1.3 任务拆解规则

- 按「F14 公式定义器」单模块垂直切片，先文档后契约、先引擎底座后管理面、先数据后接口、先后端后前端、先联调后收尾。
- 后端按「依赖引入与常量 → SPI/Registry → 内置函数 → 引擎 → 沙箱 → 模型/Mapper → Service/Resolver → Controller」八步推进，每步一个主产出与一条验证路径。
- `service/engine` 为经方案确认的 service 次级包（AGENTS.md「必要时增次级包」条款），包结构以方案 §4.1 为准。
- 文档同步不靠「顺手更新」：Wave 0 显式补四份系统模块文档章节，收尾设回查任务；Controller Swagger 注解与代码同批完成。
- 验证基线：`cd backend && ./mvnw test`（含 `ApiDocsTest`、沙箱安全用例）、`cd frontend && npm run build`；集成验证期启动的服务结束前停止。
