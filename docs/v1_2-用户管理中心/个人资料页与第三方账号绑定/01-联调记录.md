### 3.2 GET /openid/callback（无/伪造 state）→ 302 expired
- 步骤：无 token 直调四个变体：伪造 state、空 state、无参、带 code 无 state。
- 上次记录（V1.0）：三变体全部 `HTTP 200 + {"code":"ERROR","message":"系统异常，请稍后重试或联系管理员"}` —— FAIL。
- **根因定位（本次实测链）**：
  1. Redis 已运行（PONG）后重测：仍 `200 系统异常` —— 推翻「① Redis 未运行导致 getAndDelete 抛异常」假设；
  2. 取后端日志堆栈：`org.springframework.data.redis.RedisSystemException: Error in execution ← io.lettuce.core.RedisCommandExecutionException: ERR unknown command `GETDEL`, with args beginning with: `openid_bind_state:`；
  3. `redis-cli info server` → **redis_version:5.0.14.1（Windows 便携版）；`redis-cli getdel` → `ERR unknown command`** —— GETDEL 需 Redis ≥6.2（Spring Data Redis `opsForValue().getAndDelete()` 映射 GETDEL）。方案 D11 假设「RedisTemplate 已就绪」对客户端成立、对服务端版本不成立；
  4. 推翻「② redirect_base 为空串导致 302 组装抛异常」假设：302 组装对空 base 不抛异常（base=null 时 Service 返回 null、Controller 转 400「回调地址未配置」，为 Swagger 已注解的设计行为，且有单测 `handleCallbackReturnsNullWhenRedirectBaseMissing` 钉住）；异常发生在更早的 state 取删阶段，两者此前均未暴露仅因堆栈被全局兜底掩盖。
- **修复（DEF-1，特性代码内最小修复）**：`SysOrgProfileService` 新增 `takeState`——优先 `getAndDelete()`（≥6.2 原子路径不变），捕获 `DataAccessException` 降级 `GET+DEL` 两段取删（非原子，并发窗口与 6.4 查重口径同量级）；`SerializationException`（state 值损坏/格式不兼容）按 expired 降级（回调为浏览器 302 导航，方案 4.4「任何失败均 302 带 fail_reason，不返回 JSON 错误页」）；Redis 宕机仍上抛不做静默。新增 3 个单测（降级成功路径 / 降级缺 state→expired / 损坏值→expired）。
- **DEVIATION-1（配置默认值）**：`redirect_base` 原 yml 默认 `""` 导致（GETDEL 修复后）callback 回 `400 回调地址未配置` 而非 302 expired。按方案分层口径将 `properties/sys/org/application.yml` 的 `SETTING.openid.redirect_base` 默认值设为 `http://localhost:5173`（本机前端 dev server）；重启后 `syncSetting` 日志 `setting default updated: type=openid, key=redirect_base, value=http://localhost:5173, keepUserValue=false`，`common_setting` 行 value/default 同步更新（未手工改库）。生产部署必须经 `CS_ORG_OAUTH_REDIRECT_BASE` 覆盖（yml 注释已注明）；方案 4.4 yml 示例字面（`redirect_base: ""`）待 PF5-DOC-001 勘误。接口路径/方法/ACTION 常量零改动。
- 修复后实测（curl -i）：
  | 变体 | 实测 |
  | --- | --- |
  | `?state=fakestate123` | `HTTP/1.1 302` + `Location: http://localhost:5173/profile?bind=expired` |
  | `?state=`（空值） | 同上 `302 …bind=expired` |
  | 无参 | 同上 `302 …bind=expired` |
  | `?code=abc`（无 state） | 同上 `302 …bind=expired` |
- 结论：PASS（修复后；记 DEVIATION + 已修复）
