## 组织架构列表页面

- 为 sys_org_element 表添加字段：field_pinyin 拼音全称； field_pinyin_short 拼音简称；自动随 field_name 字段变化而更新；

在 【组织架构】 菜单增加 【组织架构列表】 页面，放在 【当前组织架构】 后；

该页面实现对 机构、部门、人员、岗位 的列表查询；

查询项：类型【机构、部门、人员、岗位】（默认人员）；关键字（名称，编号，拼音，拼音简称模糊匹配）；启用状态（默认是）；

列表项：编号、名称、上级组织架构、状态、创建时间、创建人、更新时间、更新人；

按钮：新增、编辑、启用/停用、导入、导出；

## 组织架构导入导出

将当前的 SysOrgUserProperties.ACTION_IMPORT 和 SysOrgUserProperties.ACTION_EXPORT 作废，替换为 SysOrgElementProperties.ACTION_IMPORT 和 SysOrgElementProperties.ACTION_EXPORT；

实现 【组织架构-组织架构列表】 页面上的导入导出按钮；

导出为当前查询条件导出；

导入弹窗设置项包括：导入方式【新增，覆盖，新增并覆盖】；导入组织机构【机构、部门、人员、岗位】；失败处理【忽略，终止】；

导入模板根据导入组织机构【机构、部门、人员、岗位】不同而变化；

机构模板：编号、名称、是否启用、上级组织架构编号、是否虚拟组织、联系电话、联系邮箱、联系地址；

部门模板：编号、名称、是否启用、上级组织架构编号、是否虚拟组织、联系电话、联系地址；

人员模板：编号、名称、是否启用、上级组织架构编号、是否虚拟组织、联系电话、联系邮箱、联系地址、性别、出生日期、登录名、在职状态、账号状态；

岗位模板：编号、名称、是否启用、上级组织架构编号、是否虚拟组织、负责人编号；

## 用户信息拓展

增加 sys_org_user_expand 表，记录用户信息拓展字段项：

```
sys_org_user_expand {
  field_id varchar(32),
  field_order int 序号,
  field_name varchar(200) 字段名,
  field_type varchar(32) 字段类型（仅提供 文本、数字、日期、时间、日期时间、单选、多选）,
  field_length int 字段长度（仅文本类型填写）,
  field_enums varchar(2000) 字段枚举（仅单选、多选填写；用 ";" 分割）,
}
```

增加【组织架构-用户拓展信息】页面，放在【组织架构-群组】后面；

用户拓展信息页面直接为编辑页面，不提供列表和详情页面；直接在该页面上通过明细表方式维护拓展信息字段；

拓展信息字段维护权限为【组织架构-用户】的【编辑】权限；

在 sys_org_user 表中增加 field_expand 字段，用于保存用户信息扩展信息，使用 json 格式保存；

在 个人资料 页面中增加 【拓展信息】 栏，显示与维护用户信息拓展信息；
