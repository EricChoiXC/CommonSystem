## 六、ERP 系统接入指引

本工程为独立可运行的 Spring Boot 单体（后端 + 前端骨架），ERP 系统接入公共模块有两种典型方式：

1. **作为独立公共服务**：ERP 前后端通过网关 / HTTP 调用本服务的登录认证、组织架构、附件、通知待办、流程、日志、码值等接口；本服务自带数据库表与 Redis 缓存。
2. **作为依赖模块合并**：将本工程后端以 Maven 依赖（或源码合并）方式引入 ERP 工程，共享同一数据库与 Redis；前端按菜单裁剪说明将公共页面并入 ERP 前端路由。

接入时的注意事项：

- **数据库**：共享数据库时，本工程 13 个 Flyway 脚本与 ERP 侧脚本按版本号合并执行；`V1_01_020` 涉及 erp 表，保留在 ERP 工程内执行，避免重复或冲突。
- **环境变量**：本工程环境变量前缀为 `CS_*`（如 `CS_DB_PASSWORD`）；若部署环境沿用 `ERP_*` 前缀，需在部署配置中补齐映射。
- **配置键**：附件存储路径配置键为 `common.att.storage-path`，ERP 侧原 `erp.att.storage-path` 需同步改名或双写。
- **前端存储键**：本工程使用 `common_token` / `common_visited_tabs`；与 ERP 前端同域名共存时注意键名冲突与互踢问题。
- **启动任务**：本工程 `SysStartupTask` 不含 `ErpMdmBizTypeLoader`；ERP 工程合并本模块后，该任务保留在 ERP 侧自行注册。
- **命名还原**：如需把本工程的增量改动同步回 ERP 工程，按第四章对照表反向替换（`com.common.system` → `com.project.backend` 等）。
