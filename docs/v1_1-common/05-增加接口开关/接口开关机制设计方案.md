1. 数据库增加模块组状态表

```
common_module {
  field_id,
  field_key varchar(200) not null comment '模块标识',
  field_name varchar(200) not null comment '模块名称',
  field_status tinyint(1) not null default 1 comment '模块状态 0 关闭 1 开启',
  field_remark varchar(200) comment '模块描述',
  field_update_time timestamp not null default current_timestamp on update current_timestamp comment '更新时间'
}
```

2. 模块组数据来源

在 'resources/properties/' 下，各模块创建自己的 'module.yml' 文件，文件结构示例如下：

```yaml
module-group:
  calendar:
    name: 日程
    remark: 日程模块
  third-party:
    name: 第三方
    remark: 第三方账号接入模块
  # ... ...
```

3. 系统启动时，读取 'resources/properties/' 下的 'module.yml' 文件，并解析成模块组数据，并保存到数据库中。新导入模块默认 开启；

4. 增加注解 @ModuleGroup， 可添加到类和方法上；一个必填字段 'moduleGroupKey'，对应 common_module.field_key

5. 在 SpringMVC 拦截器中，拦截请求，判断请求的模块组是否开启，如果未开启，则返回接口未开启错误；

6. 模块维护：

6.1 增加【系统管理-模块管理】菜单项；

增加【模块管理】页面，页面上通过四分栏布局，以卡片形式展示模块组，显示模块组名称、描述、状态、和开关闭按钮；

6.2 后端增加权限：模块组管理员；增加接口：模块组列表（不设权）、模块组状态切换（模块组管理员）；
