## 改造说明

> 状态说明（2026-11-17）：本方案已按评审裁决落地为注解引擎（2026-11-16 评审 → 2026-11-17 全量落地），本文保留为需求还原与原始注解草图的历史底稿，正文不再修订，现行口径以 [注解维护表结构设计方案.md](注解维护表结构设计方案.md) 为准。

针对项目开发周期经常进行表结构维护，和该项目将作为其他项目的功能基底，使用 flyway 脚本管理数据库结构可能存在版本号异常、脚本过多的问题；
因此采用类似 'jakarta' 的注解方案进行表结构维护和数据源管理；

## 改造方案

### 类注解

```java
// 表注解
public @interface TableSource {
    //    表名
    String name();
    // 是否自动更新
    boolean autoUpdate() default true;
    // 索引
    Index[] indexs() default {};
}
// 数据源注解
public @interface DataSource {
    // 数据源名
    String name();
}
// 索引注解
public @interface Index {
    // 索引名
    String name();
    // 索引字段
    String[] indexColumns();
    // 索引类型
    String indexType() default "BTREE";
}
```

### 字段注解
```java
// 表字段注解
public @interface ColumnField {
    // 字段名
    String fieldName();
    // 中文名，数据源名
    String sourceName();
    // 字段类型
    String fieldType() default "STRING";
    // 长度
    int fieldMaxLength() default 200;
    // 小数位
    int fieldDecimalLength() default 0;
    // 是否主键
    boolean primaryKey() default false;
    // 是否非空
    boolean nullable() default false;
    // 默认值
    String defaultValue() default "";
}
// 对象字段注解（外键，主表对象[一对一，多对一]）
public @interface ObjectField {
    // 字段名
    String fieldName();
    // 中文名，数据源名
    String sourceName();
    // 是否创建外键
    boolean PkKey() default false;
    // 联表方式
    String linkType() default "LEFT";
    // 联表字段
    String linkColumn() default "fieldId";
}
// 列表对象注解（明细表[一对多]、中间表[多对多]）
public @interface ListObjectField {
    // 是否中间表
    boolean isMiddleTable() default false;
    // 中间表名
    String middleTableName() default "";
    // 中间表对方字段
    String targetIdField() default "";
    // 中间表的我方字段 或 一对多上多方的我方id字段
    String myIdField() default "";
}
// 数据源字段注解
public @interface DataSourceField {
    /** 显示名（配置表单与前端表头），必填 */
    String label();
    /** 值类型：STRING / NUMBER / DATE / DATETIME；空 = 按 Java 字段类型推导（显式声明优先且须合法） */
    String type() default "";
    // 是否查询字段
    boolean queryField() default true;
    // 是否输出字段
    boolean outputField() default true;
    /** 允许的操作符（SysDatasourceOp 名称）；返回字段定义时忽略；条件字段为空 fail-fast */
    String[] ops() default {};
    /** 是否允许字面量值；false 时仅接受运行时变量（如 fieldCreatorId 只收 ${CURRENT_USER_ID}，防越权） */
    boolean literalAllowed() default true;
    /** 是否可作为排序列（供 /query sortField 白名单校验；仅返回字段定义使用） */
    boolean sortable() default false;
    /** 输出顺序（Class.getDeclaredFields 不保证声明序，显式控制；公共字段 fieldId 固定最前） */
    int order() default 0;
}
```

## 裁决结论（2026-11-16）

评审确认立项，完整裁决记录见 [方案分析.md](方案分析.md) §7。要点：

- **路线**：先补设计文档（同步语义矩阵、存量接驳、门禁、锁、审计、注解定稿）评审通过后再实现；
- **注解族**：收敛到新包 `com.eric.base.common.source`；保留 `@TableSource` / `@ColumnField` / `@Index` / `@DataSource`，砍掉 `@ObjectField` / `@ListObjectField`；已实现的 A8 `@DatasourceField` 迁入该包替换为 `@DataSourceField`，引用点同批迁移；
- **Flyway**：纯替换——移除依赖与 `spring.flyway` 配置，`flyway_schema_history` 留档；数据回填走 Java 编码迁移通道（DataMigration SPI）；
- **门禁**：`CS_DS_SYNC_MODE` 三段式（dev=APPLY、test/prod=VALIDATE）+ 挂 `SysStartupTask#run` + `GET_LOCK` 互斥；
- **存量表**：反向生成工具导入注解后 adopt（比对差异而非重建）；
- 本草稿遗留的设计问题（类型枚举化、N1~N4 等 13 项）见方案分析第 3 节，随设计文档定稿逐项解决。
