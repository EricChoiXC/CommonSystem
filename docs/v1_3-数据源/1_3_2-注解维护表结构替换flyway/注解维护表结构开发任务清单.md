### 1.2 当前版本范围

- 版本目标：交付「注解维护表结构」框架能力——五注解族 + 同步引擎（VALIDATE/INSTALL/APPLY 三模式门禁）+ DataMigration SPI + 反向生成工具，存量 21 表注解化 adopt 后纯替换 Flyway。
- In Scope：
  - `com.eric.base.common.source` 包：annotation / enums / model / scanner / ddl / diff / service / spi / dao / tool；
  - 两张审计表（引擎自举）+ Dao/Mapper；
  - `CS_SOURCE_SYNC_MODE` 三段式配置与 `SysStartupTask` 挂载（第十二/十三个启动任务）；
  - 存量 21 表分批标注 adopt；A8 `@DatasourceField` 迁移；
  - Wave 3.5 增补（方案 1，2026-11-17）：`@TableSource` 表级主键列集声明能力 + 9 张无 field_id 主键表纳管（见 §3.5）；
  - Flyway 依赖与配置移除、`db/migration/` 存档化。
- Out of Scope（设计方案 §10）：多数据库方言、改名/删列自动化、快照 hash 优化、FULLTEXT、视图/存储过程、前端（无页面）。
- 影响范围：`backend/src/main/java/com/eric/base/common/source/`、`backend/src/main/java/com/eric/base/sys/**`（实体标注 + A8 迁移）、`backend/src/main/resources/{mappers/common/source,db/migration}`、`backend/pom.xml`、`backend/src/main/resources/application.properties`、`docs/`。

### 1.3 任务拆解规则

- 引擎核心先于接驳：先让引擎在试点表（`sys_datasource`）上跑通三模式，再批量标注存量表。
- Flyway 移除是全清单最后的硬闸门任务（D13）：adopt 比对归零 + 空库冷启动验证通过前，Flyway 依赖与配置不得移除（否则新库无法建表）。
- 每个实体标注批次以「VALIDATE 比对零 diff」为独立验收路径。
- 文档同步不靠顺手更新：Wave 0 评审裁决、Wave 4 显式修订四份文档。
- 验证基线：`cd backend && ./mvnw test`；引擎行为验证用本地 MySQL（dev 库 VALIDATE/APPLY、空库冷启动），验证期启动的服务结束前停止。
