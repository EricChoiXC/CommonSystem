### 1.2 当前版本范围

- **版本目标**：把线性串行流程引擎改造为连线（DAG）驱动的图形化流程引擎，并交付 14 类审批操作、@ProcessTask 流程任务、流程监控/统计与审批中心菜单。
- **In Scope**：连线图模型与快照、10 类节点、审批人/抄送对象解析（地址本全类型 + 公式）、串行/条件/并行/人工决策、14 类审批操作、@ProcessTask 与任务日志、通知收口（复用 READ）、LogicFlow 设计器、流程监控页、审批一级菜单（我发起的/我参与的）、流程统计（管理员/我的）。
- **Out of Scope**：独立流程变量（D8）、CANCEL 状态（D2）、CC 通知新类型（D4）、嵌套并行、超时自动处理（仅预留 Quartz 扩展点）、委托/加签/减签（初稿未列，留待后续版本）、ERP 业务侧改造。
- **影响范围**：`backend/src/main/java/com/eric/base/sys/process/**`、`backend/src/main/resources/mappers/sys/`、`backend/src/main/resources/properties/sys/process/`、`frontend/src/{views,components,api,router}`、`docs/`。

### 1.3 任务拆解规则

- 按方案设计 M1~M4 分期（决策 D1）映射为 Wave 0~4 纵向切片；模块编号统一 `P17`（v1_7 流程管理）。
- 先文档后契约、先数据后引擎、先引擎后操作、先页面后统计；每个 Wave 形成「文档→实现→联调→验证」闭环。
- 表结构一律实体注解 + 注解同步引擎，禁止新增迁移脚本；存量回填用 `SourceDataMigration`。
- 验证基线命令：`cd backend && ./mvnw test`、`cd backend && ./mvnw -Dtest=ApiDocsTest test`、`cd frontend && npm run build`。
